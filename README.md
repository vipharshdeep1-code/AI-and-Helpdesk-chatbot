## ✨ Features

- **Keyword-based matching** — No AI models or external APIs needed
- **10 IT topics covered** — Wi-Fi, passwords, slow PC, printers, software, email, VPN, crashes, display, and audio
- **Quick-reply buttons** — One-click access to the most common problems
- **Chat history** — Conversation is preserved during your session
- **Clear chat** — Reset the conversation with a single button
- **Fallback support** — Directs users to the IT Support Team when the bot can't help
- **Modern UI** — Clean sidebar with topic list, styled chat bubbles, and custom CSS

## 🚀 Getting Started

### Prerequisites

- **Python 3.8** or higher installed on your system

### 1. Install Dependencies

Open a terminal in the project folder and run:

```bash
pip install -r requirements.txt
```

### 2. Run the Application Locally (Optional)

```bash
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`. (Note: This is only accessible on your local computer while the terminal is running).

---

## 🎯 How to Use

1. Type your IT problem in the chat input box (e.g., *"My Wi-Fi isn't working"*).
2. Read the step-by-step solution provided by the bot.
3. Use the **quick-reply buttons** below the chat for common issues.
4. Click **🗑️ Clear Chat** in the sidebar to start a fresh conversation.
5. If the bot can't solve your problem, it will provide IT Support contact details.
